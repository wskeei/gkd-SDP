# Release smoke checklist

这是稳定版 Release workflow 的真实设备检查，不由 JVM/Actions 自动测试替代。记录设备型号、Android 版本、应用版本、测试日期和未覆盖项。只有版本化的稳定 Release 可以执行这份清单，Nightly Artifact 不满足 Release 完整性项目。

真机/OEM 项目不作为自动化发布门禁。稳定 Release 发布后，由用户下载公开资产自行验证；未执行的项目保持未勾选，交接时不得声称已经通过。

## 安装与版本

- [ ] 从上一稳定版升级安装，应用 ID、签名和本地数据保持兼容。
- [ ] 冷启动、热启动、应用恢复和首次启动迁移正常。
- [ ] About 页面显示正确 `versionName`/`versionCode`。
- [ ] Release 页面 APK、`update.json`、CHANGELOG 版本段和 SHA256 一致。
- [ ] 应用内“检查更新”稳定版/测试版渠道符合预期，不指向上游 GKD。

## Runtime and permissions

- [ ] Accessibility 模式启动、停止、重新连接和前台应用识别正常。
- [ ] Automation/Shizuku 模式启动、停止、前台应用识别和回桌面正常。
- [ ] 通知权限、通知渠道、前台服务和悬浮窗拒绝路径有清晰提示。
- [ ] 普通 Back、Home、最近任务划走和系统 Force stop 的行为分别符合文档。

## Digital self-discipline

- [ ] 使用申请弹窗、理由、标签、时长、申请记录和倒计时正常。
- [ ] 分别打开“添加标签”“申请理由”“自定义分钟数”输入框；软键盘出现后当前输入框、辅助文字和同一行操作按钮位于键盘上方，表单可继续滚动，关闭键盘后不残留底部空白。
- [ ] 在 360dp 竖屏、横屏、200% 字体下切换三个输入框焦点并展开/收起动态输入区；当前输入框保持可见，提交、取消、FLAG_SECURE 和申请数据语义不变。
- [ ] 新建自定义标签后，“其他”仍是标签列表最后一个 chip；首屏先看到距离上次结束使用卡，卡片下方直接是标签。
- [ ] 申请弹窗显示距离上次实际结束使用的秒级计时、近 24 小时/近 7 天/近 30 天间隔数据和间用比；范围切换清晰且不重复读取数据库。
- [ ] 取消申请不会创建记录或重置锚点；成功提交后下一次申请以本次提交为锚点。
- [ ] 间用比按“未使用间隔 ÷ 本次申请时长”计算；三种范围平均和有效样本数可见，缺失结束时间不显示为 0。
- [ ] 时长区同时显示本次间用比、所选范围平均值和同单位公式；秒、分钟、小时混合输入仍保持单位一致。
- [ ] 倒计时横向悬浮条包含理由；正常显示时截图/录屏不显示安全内容，并如实记录空白、黑块或整次捕获被拒绝等系统表现。
- [ ] 点击倒计时悬浮条后，“使用控制”在 360dp、横屏、200% 字体和深色主题下可滚动、文字完整，`隐藏 10 秒用于截图`、返回和终止按钮均可访问。
- [ ] 选择“隐藏 10 秒用于截图”后安全悬浮窗消失；分别用硬件键和快捷设置截图，在目标应用自身允许截图时画面完整且不包含倒计时或申请理由。
- [ ] 隐藏期间申请记录和倒计时继续；十秒后同一条未到期记录恢复并显示正确剩余时间，临近到期隐藏时不会在到期后恢复。
- [ ] 隐藏期间切换应用、结束会话、断开运行时或开始另一条记录，不会恢复旧应用、旧理由或重复悬浮窗。
- [ ] 目标应用自身设置 `FLAG_SECURE` 时仍可能拒绝截图；记录为目标应用限制，不误判为 GKD-SDP 悬浮窗未移除。
- [ ] 应用拦截和应用组时间规则命中；无有效时间规则时不会误拦截。
- [ ] Self Control 应用拦截显示秒级计时和间隔图表，只有覆盖层成功挂载才新增一次事件；重复启动/挂载失败不重复计数。
- [ ] 应用、选择器和网址拦截只与自己的稳定 key 配对；选择器使用实际前台应用，网址不泄露 URL/pattern。
- [ ] Self Control 拦截、经过时长和只回桌面的行为正常；洞察读取失败时 10 秒倒计时和退出仍可用。
- [ ] 选择器拦截页显示订阅/规则组/exact rule，首页触发记录区分已执行与已拦截；应用/URL 拦截页显示安全规则来源。
- [ ] 拦截页默认显示近 24 小时，可切换近 7 天/近 30 天；当前已挂载事件作为固定最新点，不生成虚假 0。
- [ ] 12 次同小时有效样本显示 12 个点；超限聚合时同时显示总记录、有效样本、图形点和聚合粒度。
- [ ] URL 拦截在受支持浏览器中命中并正确处理跳转/覆盖层，显示自己的间隔图表。
- [ ] “数字自律复盘”支持今日/近 7 天/近 30 天、申请/拦截和拦截子类型筛选。
- [ ] 复盘申请/拦截 Tab 不串数据；趋势指标、范围、拦截筛选、排行占比、最近 10 条明细和空态清晰可读。
- [ ] 复盘显示事件数、有效间隔数、平均/中位数、上一周期比较、图表、最近明细和目标排行；无样本不显示为 0。
- [ ] 复盘跨午夜、切换时区和手工调整系统时间后范围边界正确；TalkBack、200% 字体、360dp、横屏、深色主题可用。
- [ ] beta.3 → 新版升级保留 Room 数据并完成 32 → 33；旧申请缺少实际结束时间时不回填，新的可信记录可正常统计。
- [ ] 90 天清理和 10,000 行上限可用构造数据验证；申请记录不被新事件清理逻辑删除。
- [ ] 专注模式白名单、锁定和退出路径正常。
- [ ] 自动重开保护、锁定模式和无障碍守护通知时间线正常。
- [ ] 无障碍关闭后守护的通知、倒计时、悬浮窗、前往按钮和恢复路径正常。

## Backup and restore

- [ ] 导出页默认选择普通设置、订阅、自律配置、自律历史和上游历史；“敏感可选数据”默认关闭并显示快照、无障碍事件日志和联系人说明。
- [ ] 少于 12 个 Unicode 字符或两次不一致的密码不能导出；有效密码可通过 SAF 保存 `GKDSDPBK2` 文件，界面和诊断中不出现密码、外部 Uri 或底层解密异常。
- [ ] 使用错误密码、被修改或截断的 v2 文件时显示稳定错误提示，现有 Room、Store、订阅文件和运行时状态完全不变。
- [ ] 正确密码导入先显示格式、类别及每类新增/覆盖/删除数量；取消二次确认不修改数据，确认后只替换备份包含的类别并刷新订阅与自律运行时。
- [ ] 构造导入中断或失败后重新启动，主界面开放前完成回滚；原有配置、历史、锁定状态、订阅文件和未包含类别保持一致，不新增虚假触发或使用记录。
- [ ] 导入上一稳定版生成的旧版未加密 ZIP，只接受 `store/`、`db.json` 与 `subscription/` 已知文件，展示旧版格式提示并通过同一冲突预览；包含未知路径、重复路径、符号链接或可执行条目的文件被拒绝。
- [ ] v2 导出内容不含诊断日志、崩溃、缓存、支持包、私有 Store、诊断盐、远程会话、密钥或命令脚本；仅在显式选择时包含敏感可选数据。

## Release integrity

- [ ] `apksigner` 证书 SHA-256 与记录一致。
- [ ] `sha256sum --check SHA256SUMS.txt` 通过。
- [ ] `gh attestation verify` 通过。
- [ ] 日志和 Artifact 没有 keystore、密码、token 或个人申请内容。

## GitHub Actions dry-run

- [ ] 在 `release` Environment 配置四个 signing secrets 和 `RELEASE_CERT_SHA256` variable。
- [ ] 从受保护的 `main` ref 手动运行 `Release` workflow，保持 `publish=false`；没有明确 tag 时只产生 7 天 Artifact，不创建 Release/tag；feature branch 运行应被跳过。
- [ ] 若提供已有 tag，检查元数据、tag ancestry、签名指纹、APK SHA-256 和 provenance attestation。
- [ ] 真实 tag workflow 成功后先检查 Draft Release 的三项资产和 release notes，确认无敏感内容、checksum 和 attestation 后再手动发布。
