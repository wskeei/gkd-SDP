# v2.1.0 Quality Gates Adaptation Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Restore the quality-gate infrastructure required by the protected `main` branch while keeping the application source, Room schema, permissions, and user-facing behavior on the v2.1.0 development baseline plus the explicit screenshot mode.

**Architecture:** Keep the repository-level CI job names required by `main-protection`, but adapt every job to capabilities that exist in the v2.1.0 tree. Kover and Compose Screenshot validate the existing JVM/UI surfaces; managed-device tests exercise the existing application startup contract on API 26 and API 35; the baseline-profile and macrobenchmark module measures the restored application itself. No later-version business modules, database migrations, navigation architecture, backup format, or UI surfaces are restored.

**Tech Stack:** GitHub Actions, Gradle 9/AGP, Kotlin, Kover, Compose Screenshot Testing, Android Managed Devices, AndroidX Baseline Profile/Macrobenchmark, Python contract tests.
